# Google 로그인 설정하기

로그인을 켜면 첫 판을 마친 플레이어에게 "Google 계정으로 저장하기"를 권하고,
가입한 플레이어의 도감은 계정에 저장되어 휴대폰·PC 어디서든 이어집니다.

설정 전에도 게임은 그대로 동작합니다. (`js/firebase-config.js`가 `null`이면 로그인 기능만 꺼져 있고, 기록은 브라우저에 저장됩니다.)

전체 작업은 10~15분 정도 걸립니다.

## 1. 게임을 공개 주소로 올리기 (GitHub Pages)

로그인 창은 Claude 링크 안에서는 열 수 없어서, 공개 주소가 필요합니다.

1. GitHub 저장소 → **Settings** → 왼쪽 **Pages**
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main**, 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 이 주소에서 게임이 열립니다: `https://maniandmc.github.io/life-sim-game/`

## 2. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 접속 → **프로젝트 만들기**
2. 이름은 자유 (예: `life-sim-game`)
3. Google 애널리틱스는 꺼도 됩니다.

무료 요금제(Spark)로 충분합니다. 결제 정보는 넣지 않아도 됩니다.

## 3. Google 로그인 켜기

1. 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**
2. **로그인 방법(Sign-in method)** 탭 → **Google** → **사용 설정**
3. 프로젝트 지원 이메일을 고르고 **저장**

## 4. 게임 주소를 허용 목록에 넣기

1. **Authentication → 설정(Settings)** 탭 → **승인된 도메인(Authorized domains)**
2. **도메인 추가** → `maniandmc.github.io` 입력 → 추가

`localhost`는 처음부터 들어 있어서, 내 컴퓨터에서 `python3 -m http.server`로 띄워 테스트할 수도 있습니다.
(`index.html`을 더블클릭해서 여는 방식은 로그인이 되지 않습니다.)

## 5. 기록 저장소(Firestore) 만들기

1. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
2. 버전을 고르라고 하면 **Standard**
3. 위치: **asia-northeast3 (서울)** — 나중에 바꿀 수 없으니 확인하세요.
4. **프로덕션 모드**로 시작 → 만들기
5. **규칙(Rules)** 탭 → 내용을 모두 지우고 이 저장소의 `firestore.rules` 내용을 붙여 넣기 → **게시**

이 규칙 덕분에 각 플레이어는 자기 기록만 읽고 쓸 수 있습니다.

## 6. 설정값 복사하기

1. 왼쪽 위 **톱니바퀴 → 프로젝트 설정** → **일반** 탭 아래 **내 앱**
2. 웹 아이콘 `</>` 클릭 → 앱 닉네임 입력 (Firebase 호스팅은 체크하지 않음) → **앱 등록**
3. 화면에 나오는 `const firebaseConfig = { ... };` 부분을 복사

이 값을 Claude에게 보내 주면 연결해서 올려 드립니다. 직접 넣으려면 `js/firebase-config.js`의
`const FIREBASE_CONFIG = null;`을 복사한 `{ ... }` 내용으로 바꾸면 됩니다.

> 이 값들은 비밀번호가 아니라 "어느 Firebase 프로젝트인지" 알려 주는 공개 식별 정보라서 GitHub에 올려도 괜찮습니다.
> 데이터 보호는 5번의 보안 규칙과 4번의 승인된 도메인이 맡습니다.

## 7. 확인

1. `https://maniandmc.github.io/life-sim-game/` 에서 한 판을 끝까지 플레이
2. 결과 화면의 **Google 계정으로 저장하기** → 로그인
3. 다른 기기에서 같은 주소로 들어가 시작 화면의 **Google로 로그인** → 같은 도감이 보이면 성공

## 동작 방식 요약

- 첫 판은 가입 없이 플레이하고, 기록은 브라우저에 저장됩니다.
- 첫 판을 마치면 결과 화면에서 가입을 권합니다. "나중에"를 누르면 5판 뒤에 다시 권합니다.
- 가입(로그인)하는 순간 이 브라우저의 도감과 계정의 도감을 합칩니다. 판마다 고유 번호가 있어서 여러 번 합쳐도 중복으로 세지 않습니다.
- 로그아웃하면 이 브라우저에서는 기록이 지워집니다. 계정에는 그대로 남아 있고, 다시 로그인하면 돌아옵니다.
- 계정에는 도감 기록(이름·나이·사망 원인·칭호·점수)만 저장합니다.
