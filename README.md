# 인생 한 판

0살부터 죽을 때까지, 매년 일어나는 사건 속에서 선택하며 한 사람의 인생을 살아 보는 텍스트 인생 시뮬레이션입니다.
죽으면 점수·칭호·묘비명이 나오고, 그 인생을 한 장의 그림으로 만들 수 있는 **이미지 생성 프롬프트**를 만들어 줍니다.

- 분위기: 상황은 현실적으로, 문장은 유머 있게
- 한 판 길이: 보통 8~12분, 길어도 15분 안쪽 (자동 진행 버튼으로 더 빠르게 가능)
- 설치 없이 브라우저에서 실행 (HTML·CSS·JavaScript)

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 로컬 서버로 띄우려면:

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

조작: `다음 해` 버튼 (PC에서는 스페이스/엔터), 사건 선택지는 숫자 키 1~5.

## 게임 구조

1. **출생 (랜덤)**: 12가지 가정 환경(재벌가, 치킨집, 시골 농가, 보육원, 빚더미 가정 등)과 10가지 타고난 특성
2. **매년 진행**: 수입·지출, 노화와 생활습관, 사업 실적, 숨은 질병이 계산되고, 나이와 상황에 맞는 사건이 일어남
3. **사건 146개**: 돌잡이부터 수능, 군대, 취업, 연애·결혼, 창업과 파산, 투자, 투병, 은퇴, 손주, 키오스크까지
4. **죽음 (27가지)**: 노환, 질병, 사고, 무모한 도전, 황당 사고(운석, 자판기…). 일찍 죽는 원인은 대부분 쌓아 온 선택의 결과
5. **엔딩**: 점수(수명·평균 행복·관계·재산·업적 × 출발점 보정), 칭호 22종, 묘비명, 조문객 수, 인생 그래프, 그림 프롬프트
6. **도감**: 지금까지 겪은 사망 원인과 칭호를 모으는 수집 요소

**출발점 보정**이 핵심 규칙입니다. 보육원(×1.3)이나 빚더미 가정(×1.2)에서 태어나면 같은 결과도 더 높게 평가하고, 재벌가(×0.8)는 기대치가 높습니다. 어디서 태어나든 높은 점수를 노릴 수 있습니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `js/data/base.js` | 출생 환경, 특성, 직업, 사업, 업적, 이름 |
| `js/data/events-early.js` | 0~19세 사건 |
| `js/data/events-adult.js` | 20~64세 사건 (군대, 취업, 결혼, 창업, 투자, 건강, 직업별 이야기, 모험) |
| `js/data/events-late.js` | 은퇴·노년·자녀 사건, 선택 없이 일어나는 운 사건 |
| `js/data/deaths.js` | 사망 원인 (문장, 묘비명, 그림용 장면) |
| `js/data/endings.js` | 칭호, 점수 계산, 조문객 |
| `js/engine.js` | 한 해 진행, 사건 고르기, 선택 결과 적용, 사망 판정 |
| `js/prompt.js` | 인생 그림 프롬프트 생성 |
| `js/main.js` | 화면, 저장(localStorage), 인생 그래프 |
| `tools/simulate.js` | 수천 번 자동 플레이로 균형과 오류 점검 |

## 사건 추가하기

`js/data/events-*.js`의 `EVENTS.push(...)` 안에 객체 하나를 추가하면 됩니다.

```js
{
  id: 'karaoke', age: [20, 60], once: false, cooldown: 5,   // 5년마다 다시 일어날 수 있음
  title: '노래방',
  text: '회식 2차로 노래방에 왔습니다. 마이크가 당신 앞에 놓였습니다.',
  choices: [
    { label: '18번을 부른다', result: '점수 98점! 기계가 당신을 인정했습니다.', effect: { happy: 5, relation: 3 } },
    {
      label: '탬버린만 친다',
      outcomes: [   // 결과가 확률로 갈리는 선택지
        { w: 70, result: '탬버린 장인으로 등극했습니다.', effect: { relation: 4 } },
        { w: 30, result: '손목이 나갔습니다.', effect: { health: -3 } },
      ],
    },
  ],
}
```

- `effect`: `health`, `happy`, `smarts`, `relation`(능력치 증감), `money`(만 원), `set`(상태 저장), `job`, `achieve`, `death`, `moment`(엔딩 하이라이트와 그림 프롬프트에 들어갈 장면), `run`(복잡한 처리)
- `priority: true`는 조건이 맞으면 그해에 반드시 일어나는 사건입니다 (수능, 입대 등).

수정한 뒤에는 검증 도구를 돌려 보세요.

```bash
node tools/simulate.js 3000
```

평균 수명, 예상 플레이 시간, 사망 원인·칭호·등급 분포, 한 번도 안 나온 사건, 문장 속 빈칸(`{name}` 같은 치환 누락)을 보여 주고, 문제가 있으면 실패로 끝납니다.
